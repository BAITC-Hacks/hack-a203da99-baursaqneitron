# Классификатор обращений

Веб-версия и консольный скрипт для тестового задания: читают обращения,
присваивают каждому категорию (**справка / жалоба / другое**) и дают черновик
ответа на русском.

## Веб-версия (проще всего)

Откройте `index.html` двойным кликом в любом браузере. Пишете обращения в поле
слева — категория и ответ появляются сразу, в реальном времени. Всё считается
в браузере, интернет и Python не нужны. Кнопки: скачать `messages_out.txt`,
скопировать результат.

## Консольная версия

Читает `messages.txt` и создаёт новый файл `messages_out.txt` — по одной строке
на обращение в формате `обращение | категория | ответ`. Исходный `messages.txt`
не изменяется.

## Как пользоваться

1. Откройте `messages.txt` и впишите свои обращения — по одному на строку.
2. Запустите:

```bash
python classifier.py
```

3. Рядом появится `messages_out.txt`, а те же строки выведутся в консоль.
   Пути можно задать флагами `--file` (вход) и `--out` (результат).

Нужен Python 3.8+ (из коробки, только стандартная библиотека).

Классификация не «первый совпал», а по сумме баллов, поэтому формулировка
устойчивее:
- жалобы: сильные маркеры («не работает», «течет», «пропал», «нет денег»,
  «нахамил», …) — 3 балла, слабые («проблем», «сложност», …) — 1;
- справки: вопросительные зачины («как», «где», «сколько», «подскажите», …) —
  2 балла, тематические («справка», «расписание», «парковка», …) — 1;
- вложенные маркеры не дублируются; побеждает больший балл, при равенстве —
  жалоба; если баллов нет — «другое».

Итого 175 маркеров жалоб и 91 справок. В веб-версии видно, какие слова
сработали (чипы) и соотношение баллов (полоска).

Можно передать классификацию одному вызову LLM — для этого задайте переменные
окружения и добавьте флаг `--llm`:

| Переменная       | Что это                              | Пример                          |
|------------------|--------------------------------------|---------------------------------|
| `LLM_BASE_URL`   | API-endpoint (OpenAI-совместимый)    | `https://api.openai.com/v1`     |
| `LLM_API_KEY`    | Ключ от хостинга модели              | `sk-...`                        |
| `LLM_MODEL`      | Имя модели                           | `gpt-4o-mini`                   |

```bash
$env:LLM_BASE_URL="https://..."; $env:LLM_API_KEY="sk-..."; $env:LLM_MODEL="..."
python classifier.py --llm
```

Если LLM недоступен (нет ключа, сеть упала), скрипт сам откатывается на правила.

## Что получилось

Для 5 обращений из задания:

| № | Обращение                              | Категория |
|---|----------------------------------------|-----------|
| 1 | Как получить справку о месте учёбы?    | справка   |
| 2 | В столовой очередь, еда холодная.      | жалоба    |
| 3 | Хочу записаться на консультацию завтра.| другое    |
| 4 | Пропал Wi-Fi в корпусе B.              | жалоба    |
| 5 | Где парковка для гостей?               | справка   |

По каждому выводится черновик ответа. Правила отработали на всех 5 примерах без
ошибок; LLM-режим даёт более живые ответы и прощает формулировки. Меняйте
`messages.txt` как угодно — скрипт каждый раз создаёт `messages_out.txt` заново,
а сам входной файл оставляет нетронутым.
